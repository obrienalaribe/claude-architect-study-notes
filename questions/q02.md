# Question 2

Domain 1, Agentic Architecture and Orchestration. Task statement 1.3.

## Scenario

A medical publisher's coordinator agent spends 14 turns gathering summaries of 23 clinical papers. It then spawns a drafting subagent with the prompt "Write the safety section from the findings above". The draft comes back generic and cites none of the papers.

## Question

What is the most likely fix?

- **A.** Put the complete paper summaries, with their source details, directly into the drafting subagent's prompt.
- **B.** Add "Task" to the drafting subagent's allowed tools so it can read the coordinator's history.
- **C.** Tell the drafting subagent to consult the coordinator's conversation before it starts writing.
- **D.** Give the drafting subagent a longer system prompt describing how a strong, well-cited clinical safety section reads.

<details>
<summary>Answer and reasoning</summary>

**Answer: A.** A subagent starts with only what its prompt contains; it does not inherit the coordinator's conversation. "The findings above" points at context the subagent never received, so the findings have to be passed in explicitly. The Task tool was later renamed Agent; both names mean the same tool.

Why the others fail:

- **B.** The Task tool is what lets a coordinator spawn subagents. It does not share conversation history.
- **C.** The subagent cannot see that conversation, so there is nothing for it to consult.
- **D.** Style guidance does not supply the missing findings.

</details>
