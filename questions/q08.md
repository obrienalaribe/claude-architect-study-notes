# Question 8

Original practice question. Not from any exam.

## Scenario

A legal operations team uses Claude to flag risky clauses in supplier contracts. Lawyers dismiss 62% of flags as noise and have started skimming past all of them. The prompt currently says "flag anything that might be a concern".

## Question

Which prompt change is most likely to raise precision?

- **A.** Add "be conservative" to the prompt so the model raises fewer flags on each contract.
- **B.** Have the model score its confidence from 1 to 100 and hide flags under 80.
- **C.** List the specific clause categories to flag and the categories to skip.
- **D.** Ask the model to reread each flag in the same response and drop the ones it doubts.

<details>
<summary>Answer and reasoning</summary>

**Answer: C.** Precision improves when the prompt states which categories count and which do not. Vague instructions leave the boundary to the model, and a high false positive rate erodes trust in the accurate flags too.

Why the others fail:

- **A.** A general instruction to be conservative does not tell the model which findings matter.
- **B.** Filtering on self-reported confidence is not a substitute for stated criteria.
- **D.** Same-session self-review keeps the reasoning that produced the flag, and the criteria are still undefined.

Exam domain: 4, Prompt Engineering and Structured Output. Task statement: 4.1.
